# 🔴⚠️ OLLAMA : À INSTALLER AVANT JARVIS NEO

**Ollama doit être installé séparément** si vous voulez utiliser l'IA locale, le fallback local ou les fonctions de vision de JARVIS NEO.

Le fichier `JARVIS_NEO.exe` **n'embarque pas Ollama ni les modèles IA**.

Installez Ollama, puis installez au minimum le modèle configuré dans JARVIS NEO, par défaut `llama3.2:3b`.

Les modèles de vision nécessaires sont également à installer séparément lorsqu'une fonction de vision est utilisée.

Pour une utilisation avec Groq uniquement, configurez votre clé API dans JARVIS NEO. Ollama reste recommandé pour disposer du fallback local lorsque le cloud est indisponible ou atteint son quota.
